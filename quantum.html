FOR THE WORKSPACE OPERATORConfigure the execution connector+

Set two server-side values.

In Vercel environment settings, configure IONQ_API_KEY for the provider and ALMOND_EXECUTION_TOKEN for this app's access code (at least 32 characters). Redeploy, then check the connection above.

Choose the execution target.

The server defaults to a simulator. A QPU target requires IONQ_BACKEND and ALMOND_ALLOW_QPU=true; the browser cannot switch to hardware. Actual provider results determine what appears in the result panel.
